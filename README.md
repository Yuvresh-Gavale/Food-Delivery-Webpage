# Food Delivery Webpage
Food Delivery Webpage - Frontend Project

## Project Overview
This project is a food delivery website created using HTML and CSS. It provides a simple and user-friendly interface for exploring food delivery services.

## Features
- Navigation menu for easy browsing.
- Hero section introducing the food delivery service.
- Food gallery with multiple food images.
- Cities section showcasing service locations.
- Customer testimonials.
- Subscription plans.
- Contact form.
- Responsive layout, depending on the CSS styles implemented.

## Technologies Used
- HTML5
- CSS3

## Project Structure
The main website files are organized inside the `food project` folder.

- `index.html` — Main webpage.
- `resources/css/style.css` — Main stylesheet.
- `resources/img/` — Website images.
- `vendors/css/normalize.css` — CSS normalization stylesheet.

## How to Run
1. Download or clone this repository.
2. Open the `food project` folder.
3. Open `index.html` in a web browser.
4. Make sure the image and CSS paths remain unchanged.

## Responsive Breakpoints
Check the media queries in `resources/css/style.css` to identify the breakpoints used for mobile, tablet, and desktop layouts.
